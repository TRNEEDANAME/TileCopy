## Tile copy

- Copy a set of tiles (checkboxes to decide what gets copied : Furniture / structures -- Ground / floors -- Containers (items inside) -- Overlay (clutter / decals))
- Save the tiles into a shareable string
- Undo your last copy
- Save all of your session's copies
- Rename your copies
- Preview when selecting & pasting tiles (safehouse like tile colouring)

Made for The Last Constellation RP server, released as a separate component for aother servers
